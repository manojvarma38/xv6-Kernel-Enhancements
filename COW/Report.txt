Internal Working of Copy-On-Write :
---------------------------------------

1.)Fork with COW:

When a process calls fork(), instead of copying all pages, the kernel maps the parent’s physical pages into the child.

Writable pages are marked COW in both processes (PTE_W cleared, RSW bits set).

Reference counts for these pages are incremented.

2.)Page Fault Handling:

When a process writes to a COW page, a page fault occurs.

The kernel allocates a new physical page, copies the contents from the shared page, and updates the PTE to point to the new page with writable permissions.

Reference counts are adjusted: the old shared page count is decremented, the new page count is initialized to 1.

3.)Memory Management:

Each physical page keeps a reference count.

When a page is unmapped or a process exits, the reference count is decremented.

A page is freed only when no process is pointing it.
